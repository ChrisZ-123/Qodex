# 人格文件

每个 `.md` 文件是一张人格卡，文件名是控制台中的人格名称。`自然群友` 是公开、通用的交流伙伴示例，不包含部署者的私人身份或真实经历。升级更新这张示例卡，不强制切换现有全局角色或会话覆盖。

在控制台“全局设置 → 角色人格”选择、编辑并保存全局人格，下一轮生效；当前会话可以继承全局、选择独立人格或明确设为“无角色”。“编辑全局人格”进入全局入口。人格文本在部署内共享，角色选择和口吻允许按会话覆盖；长期记忆仍按群/私聊隔离。

回复方式是独立设置：`natural` 让模型自行组织分条和表情顺序；`single` 要求模型原生组织为一段文字，不在输出后拼接。QQ 长度限制仍可能产生传输分片。人格不能增加工具、电脑操作、其他群访问或修改游戏账户的权限。

`傲娇助手`、`小鲸鱼` 是随上游保留的示例。其中旧 DSH 工具名、模式和协议不代表当前 Codex 版本支持。当前模型模式不保证通过群消息执行旧版“进入角色扮演”等管理命令。不要把私人经历、凭据或真实群记录写入准备发布的人格文件。
