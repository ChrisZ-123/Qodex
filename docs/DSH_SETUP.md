# 上游 DSH 安装文档（历史入口）

Qodex v0.1.0 使用 Codex 自主对话后端，**不需要安装 DeepSeek Harness，也不需要执行 setup-dsh.mjs**。

当前安装步骤见 [Windows 部署指南](DEPLOYMENT.md)。

旧版 qq-bridge 的 DSH、MCP 与 preset 配置仅用于理解继承代码，原始说明保存在 [上游固定版本文档](https://github.com/Derpyu520/qq-bridge/blob/dea3ce8c408a544cf94f52a7de883fbd854e9556/docs/DSH_SETUP.md)。不要将其当成 Qodex 首次安装流程。
