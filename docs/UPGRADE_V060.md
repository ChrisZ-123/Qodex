# v0.6.0 升级与完整回退

日期：2026-10-19。适用于公开 `qodex-v0.5.0`（`aab466b`）升级到 `qodex-v0.6.0`。更旧部署先参考相应旧版升级指南。本次更新不会批量重置所有 Codex 线程，也不会强制换角色或覆盖已保存的模型、速度、图片和语音偏好。

## 停止与完整备份

用旧配置执行 `Control.ps1 -Action Stop`，确认本部署停止后，完整复制旧源码和锁文件、`config.json`、整个 `state/`、自定义角色/资源，以及任何外部 `chatMemory.directory`。备份包括独立 `state/codex-home`、会话绑定、完整历史、生成图片与本机 DPAPI 状态；它属于私人资料，不提交到 Git 或公开发布。DPAPI 数据依赖原 Windows 用户环境，跨用户不保证可解密，迁移应重新官方登录及本人绑定。

控制台 JSON 继续使用 `qq-codex-backup` **version:1**，保存 `replyMode`、分类记忆元数据及可选历史的轮次/顺序；兼容旧备份，旧条目按 `fact` 读取。记忆 schema 2、已有来源与逐条版本继续保留。缺少回复方式时使用自然回复，会话 `null` 继承。JSON 排除作者授权、玩家账号/凭据、登录票据、自动任务订阅、Codex 登录与绑定、音频、图片本体及远程登录启用配置。恢复不订阅自动任务、不重发消息，不能代替完整备份。

## 更新与验收

1. 审阅自己的本地改动，再更新到固定标签 `qodex-v0.6.0` 并运行 `npm ci`，不要强制重置私人配置与状态。首次安装可双击 `Install.bat`；已有配置由向导验证保留，QQ/Codex/玩家登录仍由本人完成。
2. 沿用本部署独立 Codex 登录。运行 `Control.ps1 -Action Start`、`Status`、`Verify`，刷新控制台；确认模型列表加载/失败重试、全局人格入口、当前会话继承及保存值。
3. 选择目标会话，检查自然/单段回复方式、记忆类别/参与 QQ/话题状态、修订恢复、运行记录中的实际使用记忆与部分发送结果。数量上限不是回复率，不以每条消息必回作为验收。
4. 若已安装鸣潮，按[鸣潮指南](WAVES.md)更新固定来源的适配器与安装状态并验证。公开默认游戏、远程绑定、实验性语音仍关闭；现有已保存值保留。作者授权与玩家登录分别检查，保存授权不等于已通过真实服务验证。
5. 本人选择真实验证范围：`ww登录` 在原群 @申请人给临时链接，SMS 完成后核对账号摘要，再由同一 QQ 确认提交绑定。不要把旧部署的自动直绑行为当成本版契约。直接用户 `ww` 签到/解绑/订阅命令执行该明确操作；模型发起的修改另需同 QQ 确认。

仅在 Codex 明确报告硬性上下文耗尽后，下一批新消息才创建新线程并载入最近最多 100 条有效历史及本轮检索记忆；失败批次不重放，旧绑定/历史仍保留。启用游戏工具仍只在相关会话下个空闲点/新线程生效。普通更新不会为所有会话制造新线程，旧原生压缩内部状态也不承诺完整复制。

## 回退

先停止 v0.6.0，并保留它的完整私人状态。恢复升级前**配套的 v0.5.0 源码、锁文件、配置和旧状态快照**，在原 Windows 用户下运行 `npm ci`、启动、验证。不要仅切换源码后让旧版本直接读取新版写过的状态。新版本期间的数据不自动合并或重发。

只改回复方式/角色时可在控制台恢复旧选择，无需删除记忆或重置上下文。只关闭游戏也不等于整套版本回退；删除账号、依赖或备份不属于默认回退步骤。候选发布的实际检查与未验项目见[验证记录](VALIDATION.md)。
