# 人格文件

每个 `.md` 文件是一张人格卡，文件名是控制台中的人格名称。首次试用建议选择 `自然群友`，或保留“自然对话（无角色）”。

在 Qodex 控制台中选择、编辑并保存人格，下一轮对话生效。人格和口吻是整个部署共享的，不按群隔离。当前 Codex 模型模式不提供通过群消息执行旧版“进入角色扮演”或“退出角色扮演”管理命令的保证。

人格只控制表达和角色设定，不会增加工具、电脑操作或访问其他群的权限。网页搜索、图片输入和发送行为仍遵循 Qodex 的固定边界。

`傲娇助手`、`小鲸鱼` 是随上游保留的示例。其中旧 DSH 工具名、模式和协议不代表当前 Codex 版本支持这些功能；使用前请在控制台调整为合适的表达设定。不要把私人经历、凭据或真实群记录写进准备提交到 GitHub 的人格文件。
